## ✨ About The Project

This project is an interactive **Image Slider** that showcases beautiful destinations around the world.

It displays images along with their titles and descriptions. Users can navigate between slides manually or let the slider automatically switch between images.

Designed with simple web technologies and smooth CSS animations.

## 🚀 Features

- 🖼️ **Beautiful Images** — Explore different destinations around the world.
- ⏭️ **Next & Previous Navigation** — Easily switch between images.
- 🔄 **Automatic Slideshow** — Images change automatically every 3 seconds.
- ⏸️ **Hover Interaction** — Automatic slideshow pauses when hovering over the slider.
- 🎬 **Smooth Animations** — Fade-in animation when changing slides.
- 📱 **Simple Interface** — Clean and easy-to-use design.
- 🌐 **Online Images** — Images are loaded from Pexels.

## ⚙️ How To Run

Follow these simple steps:

1. Download or clone this repository.
2. Extract the project folder.
3. Open the folder in **Visual Studio Code**.
4. Open `slider.html`.
5. Run the project using Live Server or open the HTML file directly in your browser.

## 🎮 How To Use

- Click the **right arrow** to view the next image.
- Click the **left arrow** to view the previous image.
- Let the slideshow automatically change images.
- Move your mouse over the slider to pause automatic navigation.
- Move your mouse away to resume the slideshow.
